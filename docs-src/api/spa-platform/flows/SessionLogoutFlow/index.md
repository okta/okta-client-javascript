# Class: SessionLogoutFlow

Browser-specific additions to [SessionLogoutFlow](/api/oauth2-flows/SessionLogoutFlow/) to perform OIDC logout

## See

* [OIDC RP-Initiated Logout](https://openid.net/specs/openid-connect-rpinitiated-1_0.html)

## Extends

- [`SessionLogoutFlow`](/api/oauth2-flows/SessionLogoutFlow/)

## Methods

### PerformPostRedirect()

> `static` **PerformPostRedirect**(`logoutUrl`, `options?`): [`Promise`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Promise)\<`unknown`\>

Performs a full-page redirect to IDP OIDC `end_session_endpoint` via generated hidden `<form method="POST">`. Performing a `POST`
request (instead of `GET` which supported by most IDPs) avoids leaking the `id_token` within the URL query params.

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `logoutUrl` | [`URL`](https://developer.mozilla.org/docs/Web/API/URL) | URL generated by [SessionLogoutFlow.start](/api/oauth2-flows) |
| `options` | [`Partial`](https://www.typescriptlang.org/docs/handbook/utility-types.html#partialtype)\<[`PostRedirectOptions`](type-aliases/PostRedirectOptions.md)\> | - |

#### Returns

[`Promise`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Promise)\<`unknown`\>

A [Promise](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Promise) which never fulfills; therefore is blocking until the full-page redirect occurs.
